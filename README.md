# 3D Visualization Order Management System — Frontend

## Overview

This repository contains the frontend of a web-based 3D visualization order management system developed using Angular.

The application provides a user interface for customers and administrators to manage visualization orders, track order statuses, explore completed projects, and interact with the platform.

The project is divided into two separate repositories: one for the frontend and one for the backend.

## Key Features

- **Order Management:** Customers can submit visualization orders, while administrators can manage incoming orders.
- **Order Status Tracking:** Customers can view the current status and progress of their orders.
- **Email Notifications:** Administrators receive email notifications when a new order is submitted.
- **Project Gallery:** Visitors can explore previously completed visualization projects.
- **Project Publishing:** Completed projects can be published with images to showcase the results.
- **Customer Reviews:** Customers can submit recommendations and feedback about their experience.
- **Website Chatbot:** An integrated chatbot helps visitors find information and answers questions about the website.

## Technologies

- **Frontend Framework:** Angular
- **Programming Language:** TypeScript
- **Styling:** SCSS
- **Markup:** HTML

## Project Repositories

This project is organized into two separate repositories.

### Frontend Repository

This repository contains the Angular client-side application, including the user interface and frontend components.

### Backend Repository

The server-side application is maintained in a separate repository:

[projectServer — Backend Repository](https://github.com/RikiGiberstien/projectServer)

The backend handles server-side functionality and supports communication between the frontend and the application's data services.

## Application Workflow

1. A customer submits a new visualization order through the application.
2. The administrator receives an email notification about the new order.
3. The administrator manages the order and updates its status.
4. The customer can follow the order's progress.
5. Completed projects can be published in the project gallery with images.
6. Customers can submit recommendations and feedback.
7. Visitors can use the chatbot to find information about the website.
